Samm-sammult 1: agendi loomine Agent Builderiga

Sobib: kõigile · andmed: sinu Outlook, kalender, Teams ja soovi korral lisatud dokumendid

Taust

Teed agendi, mis koostab sinu valitud perioodi ülesannete ülevaate Outlooki e-kirjade, ülesannete (tasks), kalendri ning Teamsi koosolekute kokkuvõtete ja stenogrammide põhjal. Agendile võid lisada ka oma dokumente, kus on ülesandeid (näiteks stenogramme).

Agent Builderis juhid ehitamist vasakul oleva abistava Copilotiga. Paremal on agendi seadistus. Põhinupud on üleval: Configure (seadistus), Preview (proovimine) ja Create (loomine).

Ettevalmistus

  • Kui sinu postkastis on vähe ülesandeid, saada endale e-kirjad 1–6 (kaust „3 E-kirjad postkasti“).
  • Soovi korral hoia käepärast mõni stenogramm, nt TRANSKRIPT_2026-10-21_Baltic_Wings_kohtumine.docx (kaust „Klient 360 näidiskaust - Baltic Wings“).

Sammud

Töövahend: Microsoft 365 Copilot → Agent Builder

1. Ava Agent Builder

Ava Microsoft 365 Copilot ja vali „Create agent“ / „Loo agent“. Avaneb vaade „Build your own specialist agent“.

2. Kirjelda agent

Kopeeri allolev kirjeldus lahtrisse „Message Agent Builder“ ja saada.

Teeme Agent Builderiga agendi, mis teeb ülevaate kasutaja valitud perioodi ülesannetest Outlooki mailide, taskide ja kalendri ning Teamsi koosolekute kokkuvõtete ja stenogrammide baasilt. Kasutaja võib lisada ka ise agendile dokumente, kus on ülesandeid (näiteks stenogramme).

3. Vaata, mis valmis sai

Abistav Copilot koostab agendi mustandi. Vasakul näed kokkuvõtet, paremal vaates Configure agendi nime, kirjeldust ja juhiseid (Instructions). Agent Builder võib luua kohe ka skilli – see on näha jaotises Skills.

4. Kontrolli teadmusallikaid (Knowledge)

Keri vaates Configure jaotiseni Knowledge → Work content. Kontrolli, et Cloud files, Outlook ja Teams on sisse lülitatud.

Web search lülita välja – ülevaade peab tulema sinu tööallikatest.

Soovi korral lisa oma dokument: „Add knowledge“ või lohista fail kasti („or just drop files here“).

5. Proovi agenti (Preview)

Vali üleval Preview ja küsi:

Koosta mulle eelmise nädala ja käesoleva nädala ülesannete ülevaade: ülesanne, tähtaeg, kellelt/kust (allikas), staatus.

6. Paranda abistava Copilotiga

Kirjuta vasakul olevale abistavale Copilotile, mida muuta. Seejärel proovi uuesti vaates Preview.

Lisa juhistesse: kui kasutaja ei ütle perioodi, küsi seda. Grupeeri ülesanded tähtaja järgi (üle tähtaja, sel nädalal, hiljem) ja märgi iga ülesande juurde allikas.

7. Loo agent

Vajuta üleval paremal Create. Jäta agent ainult endale.

8. Kasuta agenti

Ava agent Copiloti vasakult paanilt ja küsi:

Mis on minu ülesanded perioodil 01.11–30.11? Too välja üle tähtaja olevad.

Kontrolli tulemust

  • Kas ülevaates on ülesanded nii e-kirjadest, kalendrist kui ka Teamsist?
  • Kas iga ülesande juures on allikas?
  • Kas agent küsis perioodi, kui seda ei andnud?
